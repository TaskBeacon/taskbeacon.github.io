# Multiple Object Tracking Task (Web)
Browser companion to canonical `T000071-multiple-object-tracking-task`. It preserves the 2/4/6 target loads, slow/fast motion, target/distractor probes, six practice trials, 36 scored trials, timing, response semantics, and deterministic 640 x 480 H.264 stimulus set. Browser events replace PsychoPy hardware triggers.

The notify workflow dispatches `html-task-updated`. `TASKBEACON_ORG_DISPATCH_TOKEN` requires `TaskBeacon/psyflow-web` Contents read/write access and may require organization approval.
