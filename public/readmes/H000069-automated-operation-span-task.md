# Automated Operation Span Task (Web)
Browser companion to canonical `T000069-automated-operation-span-task`. It preserves 15 math-practice items, runtime mean+2.5-SD deadline calibration, three size-2 combined practice sets, set sizes 3-7 three times each, 800-ms letters, ordered recall, 85% math criterion, absolute span, and total correct. Browser event triggers replace hardware triggers; all other semantics and counts align.

The notify workflow dispatches `html-task-updated`. `TASKBEACON_ORG_DISPATCH_TOKEN` requires `TaskBeacon/psyflow-web` Contents read/write access and may require organization approval.
