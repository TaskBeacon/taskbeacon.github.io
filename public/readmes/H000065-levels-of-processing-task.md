# Levels of Processing Task (Web)

Browser companion to canonical `T000065-levels-of-processing-task`. It preserves the balanced 3 x 2 incidental-encoding design, 2 s question, 200 ms word, unexpected recognition instruction, and 60-old/120-new recognition composition.

Run through shared `psyflow-web` using `H000065-levels-of-processing-task`.

The dispatch workflow requires `TASKBEACON_ORG_DISPATCH_TOKEN` access to `TaskBeacon/psyflow-web` with `Contents: Read and write`.
